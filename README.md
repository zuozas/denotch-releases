# DeNotch releases

Downloads and release notes for [DeNotch](https://denotch.app), the Mac app that hides the notch behind a black menu bar, tidies menu bar icons and puts live widgets beside the notch.

**[Download the latest version](https://github.com/zuozas/denotch-releases/releases/latest/download/DeNotch.dmg)** · [All releases](https://github.com/zuozas/denotch-releases/releases) · [denotch.app](https://denotch.app)

Every download is signed with Developer ID and notarized by Apple. DeNotch needs macOS Tahoe 26 or later, and checks this page for updates by itself.

Questions or problems: [support@denotch.app](mailto:support@denotch.app). This repository holds releases only; DeNotch's source isn't public.
